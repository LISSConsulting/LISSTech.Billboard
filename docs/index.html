Built for IT teams

T

Toast & Modal

Non-intrusive bottom-right toasts for FYI. Full-screen centered modals when you need attention. Both support buttons and user input.

D

Dark & Light

Auto-detects Windows theme or force a specific one. Every type has matched illustrations, colors, and card backgrounds for both modes.

B

Branded

Set your org name and logo. The context footer, illustration panel, and header all adapt. Your users see your brand, not generic system chrome.

S

SYSTEM Context

Use -AsUser from SYSTEM context. Billboard routes through ServiceUI to show notifications in the logged-on user's desktop session.

R

Rich Results

Request-Billboard returns which button was clicked, its value, whether the user deferred, dismissed, or timed out. Full JSON over named pipes for IPC.

E

EV Code Signed

Every DLL, exe, and PowerShell file is signed with a LISS Consulting EV certificate. No SmartScreen warnings, no execution policy issues.

Dead simple API

Builder cmdlets compose the notification. Action cmdlets show it.

Toast
Modal + Buttons
SYSTEM Context
# Fire-and-forget info toast
$branding = New-BillboardBranding 'Contoso IT'

Show-Billboard (New-BillboardNotification -Type Info `
    -Title 'Chrome Updated' `
    -Message 'Google Chrome has been updated to version **131.0.6778**.' `
    -Branding $branding)
# Modal that waits for user response
$buttons = @(
    New-BillboardButton 'Restart Now' -Value restart -Style Primary
    New-BillboardButton 'Remind in 4 Hours' -Value defer -Style Ghost -Defer 4h
)

$result = Request-Billboard (New-BillboardNotification -Type Question `
    -Title 'Restart Required' `
    -Message 'A security update requires a restart.' `
    -Buttons $buttons -Modal)

$result.Value  # "restart" or "defer"
# From a SYSTEM-context script (Intune, N-central, etc.)
$notification = New-BillboardNotification -Type Critical `
    -Title 'Endpoint Protection Disabled' `
    -Message '**Microsoft Defender** has been disabled.' `
    -Branding (New-BillboardBranding 'Contoso IT')

# Routes through Billboard.exe + ServiceUI.exe automatically
Show-Billboard $notification -AsUser

# Or wait for response
$result = Request-Billboard $notification -AsUser
